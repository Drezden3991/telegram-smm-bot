Проверка заказчицей — SMM Bot MVP
Дата подготовки: 04.08.2026
Цель:
Получить обратную связь по удобству использования, полезности функций и необходимым изменениям перед дальнейшим развитием проекта.
Важно:
Не все пожелания автоматически становятся задачами разработки.
Каждое предложение оценивается по:
пользе для пользователя;
соответствию текущему этапу разработки;
сложности реализации;
влиянию на архитектуру.
1. Общая проверка бота
Проверить:
насколько понятно главное меню;
легко ли найти нужный раздел;
понятна ли логика действий;
нет ли лишних шагов;
удобно ли пользоваться с телефона.
Вопросы:
Есть ли места, где непонятно, что делать дальше?
Есть ли кнопки или функции, которые кажутся лишними?
Чего не хватает для ежедневной работы?
2. 👥 Раздел «Клиенты»
Проверить:
Функции:
добавление клиента;
просмотр списка клиентов;
просмотр карточки клиента;
поиск;
редактирование;
удаление.
Вопросы:
Достаточно ли информации в карточке клиента?
Какие данные о клиенте реально нужны в ежедневной работе?
Нужны ли дополнительные поля?
Возможные будущие улучшения (не задачи):
фотографии клиента;
ссылки на дополнительные соцсети;
история работы с клиентом;
файлы и материалы клиента.
3. 💡 Раздел «Идеи постов»
Проверить:
Функции:
добавление идей;
просмотр списка;
поиск;
редактирование;
удаление;
получение случайной идеи.
Вопросы:
Удобно ли хранить идеи таким способом?
Нужна ли сортировка идей?
Нужно ли разделять идеи по категориям?
Возможные будущие улучшения:
категории идей;
теги;
избранные идеи;
AI-генерация идей.
4. ✍️ Раздел «Написать пост»
Проверить:
Функции:
выбор клиента;
выбор темы;
выбор стиля;
создание поста;
сохранение истории.
Вопросы:
Насколько полезен полученный текст?
Подходит ли выбранный стиль?
Какие стили нужны дополнительно?
Нужно ли больше вариантов одного поста?
Проверить:
достаточно ли информации для создания поста;
насколько результат похож на реальный рабочий материал.
Возможные будущие улучшения:
AI-генерация постов;
улучшение текста;
изменение тона;
несколько вариантов поста;
адаптация под разные соцсети.
5. 📅 Раздел «Контент-план»
Проверить:
Функции:
выбор клиента;
выбор идей;
ввод брифа;
AI-генерация плана;
сохранение;
поиск;
редактирование;
удаление.
Вопросы:
Полезен ли формат плана на 7 дней?
Достаточно ли информации в каждом дне?
Какие поля нужны дополнительно?
Насколько результат можно использовать без доработки?
Проверить:
качество идей;
соответствие клиенту;
удобство редактирования.
Возможные будущие улучшения:
календарь публикаций;
экспорт;
расписание постов;
связь контент-плана с готовыми постами.
6. Рабочий процесс SMM
Главные вопросы:
Как обычно сейчас создаётся контент?
Какие действия занимают больше всего времени?
Какие задачи повторяются каждый день?
Что в текущем процессе больше всего раздражает?
Цель:
Понять, какие функции реально экономят время.
7. Приоритеты развития
Попросить оценить:
Что было бы наиболее полезно добавить первым:
AI-генерация готовых постов.
AI-генерация идей.
Улучшение существующих текстов.
Планирование публикаций.
Работа с несколькими клиентами.
Экспорт материалов.
Другое.
