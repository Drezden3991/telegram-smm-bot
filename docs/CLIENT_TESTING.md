# Проверка SMM Bot заказчицей

Дата передачи: 14.08.2026

Проверяй бот с телефона самостоятельно, без подсказок.

После каждого задания напиши:

- всё ли получилось;
- что было непонятно;
- что было неудобно;
- что хотелось бы изменить;
- произошла ли ошибка.

---

# Задача №1 — Главное меню

1. Запусти бота.
2. Посмотри главное меню.
3. Открой каждый раздел.
4. Вернись обратно в главное меню.

Напиши:

- понятно ли назначение разделов;
- удобно ли расположены кнопки;
- легко ли возвращаться назад.

---

# Задача №2 — Добавление клиента

1. Открой раздел «Клиенты».
2. Добавь нового тестового клиента.
3. Заполни все предложенные поля.
4. Открой карточку созданного клиента.

Напиши:

- понятно ли, что вводить;
- нужны ли все поля;
- каких данных о клиенте не хватает;
- удобно ли читать карточку с телефона.

---

# Задача №3 — Работа с клиентами

1. Найди созданного клиента.
2. Измени его данные.
3. Посмотри список всех клиентов.
4. Удали тестового клиента.

Напиши:

- удобно ли искать клиента;
- удобно ли редактировать данные;
- понятно ли, какой клиент удаляется;
- нужны ли дополнительные функции.

---

# Задача №4 — Добавление идеи поста

1. Открой раздел «Идеи постов».
2. Добавь несколько тестовых идей.
3. Посмотри список всех идей.
4. Получи случайную идею.

Напиши:

- удобно ли добавлять идеи;
- удобно ли читать список на телефоне;
- полезна ли функция случайной идеи.

---

# Задача №5 — Работа с идеями

1. Найди идею по слову.
2. Отредактируй её.
3. Удали одну тестовую идею.

Напиши:

- удобно ли искать идеи;
- понятно ли редактирование;
- понятно ли, какая идея удаляется;
- нужны ли категории или привязка идеи к клиенту.

---

# Задача №6 — Создание поста из сохранённых данных

1. Открой раздел «Написать пост».
2. Выбери сохранённого клиента.
3. Выбери сохранённую идею.
4. Выбери стиль.
5. Создай и сохрани пост.

Напиши:

- понятен ли порядок действий;
- удобно ли выбирать клиента и идею;
- подходят ли доступные стили;
- полезен ли получившийся текст;
- что в нём пришлось бы изменить вручную.

---

# Задача №7 — Создание поста вручную

1. Создай пост без клиента.
2. Выбери вариант со своей темой.
3. Введи собственную тему.
4. Сохрани пост.

Напиши:

- нужен ли вариант без клиента;
- удобно ли вводить собственную тему;
- чего не хватает при создании поста.

---

# Задача №8 — История постов

1. Открой сохранённые посты.
2. Найди созданный пост.
3. Удали один тестовый пост.

Напиши:

- удобно ли читать историю;
- легко ли найти нужный пост;
- понятно ли, какой пост удаляется;
- нужна ли возможность редактировать готовый пост.

---

# Задача №9 — Создание контент-плана

1. Открой раздел «Контент-план».
2. Выбери клиента.
3. Выбери несколько сохранённых идей.
4. Сними одну идею повторным нажатием.
5. Нажми «Готово».
6. Введи короткий бриф.
7. Создай контент-план.

Напиши:

- понятен ли выбор нескольких идей;
- удобно ли пользоваться цифровыми кнопками;
- понятно ли, что писать в брифе;
- удобно ли читать готовый план на телефоне;
- полезен ли результат для реальной работы;
- что в плане пришлось бы изменить.

---

# Задача №10 — Контент-план без клиента и идей

1. Создай ещё один контент-план.
2. Выбери вариант без клиента.
3. Пропусти выбор идей.
4. Введи собственный бриф.
5. Создай план.

Напиши:

- нужен ли такой вариант;
- понятны ли кнопки пропуска;
- достаточно ли информации для создания плана.

---

# Задача №11 — Поиск контент-плана

1. Найди сохранённый план по имени клиента.
2. Найди его по теме.
3. Попробуй найти его по тексту выбранной идеи.

Напиши:

- удобно ли пользоваться поиском;
- легко ли понять, какой план найден;
- чего не хватает в результатах поиска.

---

# Задача №12 — Редактирование контент-плана

1. Открой редактирование.
2. Выбери план кнопкой с номером.
3. Измени клиента, идеи или бриф.
4. Сохрани обновлённый план.

Напиши:

- удобно ли выбирать план из короткого списка;
- достаточно ли информации в названии;
- не слишком ли много шагов;
- нужно ли редактировать отдельный день без пересоздания всего плана.

---

# Задача №13 — Удаление контент-плана

1. Открой удаление.
2. Выбери план.
3. Нажми «Отмена».
4. Повтори выбор.
5. Подтверди удаление тестового плана.

Напиши:

- понятно ли, какой план будет удалён;
- удобно ли подтверждение;
- нужна ли возможность восстановить удалённый план.

---

# Задача №14 — Кнопка «Назад»

Во время создания поста и контент-плана нажимай «Назад» на разных этапах.

Напиши:

- всегда ли кнопка возвращает туда, куда ты ожидала;
- сохраняются ли ранее выбранные данные;
- где вместо «Назад» нужна отдельная кнопка «Отменить».

---

# Задача №15 — Свободная проверка

Используй бот самостоятельно так, как использовала бы его в реальной работе.

Попробуй создать клиента, идеи, пост и контент-план без заранее заданного порядка.

Напиши:

- что оказалось самым полезным;
- что оказалось самым неудобным;
- где было слишком много действий;
- чего не хватает для реальной работы;
- какими функциями ты бы действительно пользовалась;
- что можно убрать из бота.

---
