# Стратегические задачи

## Создание собственной библиотеки компонентов

**Приоритет:** Высокий

**Статус:** Отложено до завершения разработки SMM Bot.

### Цель

После завершения первой стабильной версии SMM Bot необходимо превратить проект из отдельного Telegram-бота в основу для разработки будущих коммерческих проектов.

Главная идея — не создавать каждый новый проект с нуля, а постепенно собрать собственную библиотеку качественных компонентов.

### Ожидаемый результат

Каждый новый Telegram-бот должен создаваться преимущественно из уже существующих компонентов.

SMM Bot становится фундаментом собственной библиотеки переиспользуемых модулей.
