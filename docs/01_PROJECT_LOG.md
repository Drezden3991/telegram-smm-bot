# Завершённый базовый MVP

## 👥 Клиенты — v1.0

Реализованы:

- добавление клиента;
- просмотр списка;
- поиск;
- удаление;
- редактирование;
- карточка клиента;
- проверка дубликатов.

Карточка клиента содержит:

- имя;
- фамилию;
- телефон;
- Instagram;
- email;
- заметки.

Данные хранятся в `clients.txt`.

## 💡 Идеи постов — v1.0

Реализованы:

- добавление идеи;
- просмотр списка;
- случайная идея;
- поиск;
- удаление;
- редактирование;
- проверка дубликатов.

Данные хранятся в `post_ideas.txt`.

## ✍️ Написать пост — базовый MVP v1.0

Реализованы:

- ввод клиента;
- ввод темы или идеи;
- выбор стиля;
- шаблонное создание поста;
- сохранение;
- история постов;
- поиск;
- удаление по ID.

Данные сохраняются в `posts.txt` в формате JSON.

## 📅 Контент-план — базовый MVP v1.0

Реализованы:

- создание статического плана по теме;
- сохранение;
- просмотр;
- поиск;
- редактирование;
- удаление.

Сценарии используют aiogram FSM. Данные хранятся в `content_plans.txt`.

- AI-регенерация при редактировании;
- выполнение синхронного SDK-вызова через `asyncio.to_thread`;
- ограничение брифа до 500 символов;
- отсутствие сохранения при ошибке API или неверной структуре;

  - авторизации;

# Текущие ограничения

- Данные хранятся в TXT- и JSON-файлах.
- Нет SQLite.
- Нет пользовательских профилей.
- Нет изоляции данных разных пользователей.
- Нет уникальных ID клиентов и идей.
- При одинаковых именах клиентов возможна неоднозначность.
- Динамические клавиатуры не имеют пагинации.
- При большом количестве клиентов и идей клавиатуры станут слишком длинными.
- Часть раздела «Клиенты» использует глобальные переменные.
- Сохранённые идеи пока не передаются в контент-план.
- Тексты постов создаются по статическим шаблонам.
- AI-генерация постов не реализована.
- AI-генерация идей не реализована.
- Нет полноценного автоматизированного тестового набора для всех разделов.
- Нет публичного деплоя.
- Бот работает только при запущенном локальном процессе Python.
- Нет production-мониторинга и журналирования.
