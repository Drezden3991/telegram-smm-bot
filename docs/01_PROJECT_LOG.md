# 📅 Контент-план — v1.1 AI-генератор

Статус реализации: ✅ Код и локальные проверки завершены  
Статус live API-проверки: ⏳ Ожидает отдельного подтверждения

## Реализовано

- создание плана по одному краткому SMM-брифу;
- OpenAI Responses API;
- модель `gpt-5.6`;
- `reasoning.effort="low"`;
- Pydantic Structured Outputs;
- ровно семь дней в порядке от 1 до 7;
- поля каждого дня: цель, тема, формат, ключевой тезис и CTA;
- форматирование результата для Telegram;
- сохранение результата в существующее хранилище `content_plans.txt`;
- AI-регенерация при редактировании существующего плана;
- выполнение синхронного SDK-вызова в отдельном потоке, чтобы не блокировать aiogram;
- ограничение брифа до 500 символов;
- отсутствие сохранения при любой ошибке API или неверной структуре;
- понятные пользовательские сообщения для ошибок авторизации, лимитов, соединения, тайм-аута и OpenAI API.

## Сохранённое поведение

- меню раздела;
- просмотр всех планов;
- поиск;
- выбор плана по номеру;
- редактирование;
- удаление;
- возврат в главное меню;
- существующий формат файлового хранилища.
