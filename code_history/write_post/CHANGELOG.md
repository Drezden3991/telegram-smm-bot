# История write_post.py

---

## v0.1 — section_menu

### Что нового
- Создан файл `write_post.py`.
- Добавлено отдельное меню раздела «Написать пост».
- Добавлены кнопки «📝 Новый пост», «📋 История постов» и «⬅️ Назад».

### Что умеет
- Открывать раздел «Написать пост».
- Показывать меню раздела.
- Реагировать на все кнопки.
- Возвращаться в главное меню.

### Ограничения
- Нельзя создать пост.
- Нельзя сохранить пост.
- История постов пока пустая.
- Нет генерации через ChatGPT.

### Почему версия сохранена
- Это первая версия раздела «Написать пост».
- Она показывает базовую архитектуру раздела через отдельное меню.

---

## v0.2 — new_post

### Что нового относительно v0.1
- Добавлен сценарий создания нового поста.
- Бот спрашивает тему поста.
- Бот создаёт простой шаблон поста по введённой теме.

### Что умеет
- Открывать раздел «Написать пост».
- Показывать меню раздела.
- Принимать тему поста от пользователя.
- Создавать простой текст поста по теме.
- Возвращаться в главное меню.

### Ограничения
- Посты не сохраняются.
- История постов пока не работает.
- Нельзя выбрать клиента для поста.
- Нельзя выбрать идею для поста.
- Нет генерации через ChatGPT.

### Почему версия сохранена
- Эта версия показывает первый переход от заглушки к созданию простого поста.

---

## v1.0 — post_manager

### Что нового относительно v0.2
- Раздел «Написать пост» доведён до полноценной версии v1.0.
- Добавлено сохранение постов.
- Добавлена история постов.
- Добавлен поиск постов.
- Добавлено удаление постов.
- Добавлен выбор клиента для поста.
- Добавлен выбор идеи или темы для поста.
- Добавлен выбор стиля поста.
- Добавлена работа через FSM без глобальных переменных `waiting_for_...`.
- Добавлено хранение постов в файле `posts.txt`.

### Что умеет
- Открывать раздел «Написать пост».
- Показывать меню раздела.
- Создавать новый пост.
- Принимать имя клиента вручную.
- Показывать сохранённые записи из файла клиентов.
- Показывать сохранённые идеи.
- Принимать тему или идею для поста вручную.
- Выбирать стиль поста:
  - экспертный;
  - продающий;
  - дружелюбный;
  - информационный.
- Сохранять созданный пост.
- Показывать историю последних постов.
- Искать посты по клиенту, теме, стилю или тексту.
- Удалять посты по ID.
- Возвращаться в главное меню.

### Ограничения
- Клиент не выбирается кнопкой из сохранённого списка.
- В списке клиентов показывается полная строка из `clients.txt`.
- Сохранённая идея не выбирается кнопкой.
- Нет полноценной интеграции с карточкой клиента.
- Нет полноценной интеграции с разделом «Идеи постов».
- Генерация через ChatGPT пока не подключена.
- Нет рерайта готового поста.
- Нет генерации нескольких вариантов поста.
- Нет SQLite.
- Хранение пока файловое.

### Почему версия сохранена
- Эта версия завершает базовый MVP раздела «Написать пост».
- Она является последней рабочей версией до полноценной интеграции разделов.

# Запланированные промежуточные учебные версии

Промежуточные версии v1.1–v1.4 были запланированы перед созданием итоговой v2.0.

Во время основной разработки их отдельный код не создавался, потому что было принято решение сразу реализовать финальную рабочую версию раздела.

Эти версии можно восстановить позже во время отдельного учебного разбора эволюции кода.

## v2.0 — integrated_post_manager

Имя сохранённого файла:

`write_post_v2_0_integrated_post_manager.py`

### Что нового относительно v1.0
- Выполнена полноценная интеграция разделов «Клиенты», «Идеи постов» и «Написать пост».
- Добавлен выбор сохранённого клиента кнопкой.
- В кнопках показываются только имя и фамилия клиента.
- Добавлена кнопка «🚫 Без клиента».
- Добавлен выбор сохранённой идеи кнопкой.
- Добавлена кнопка «✍️ Своя тема».
- Добавлено отдельное состояние FSM для ввода собственной темы.
- В создаваемый пост сохраняется копия карточки выбранного клиента.
- Добавлены переходы «⬅️ Назад» между этапами создания поста.
- Добавлена обработка пустого списка клиентов.
- Добавлена обработка пустого списка идей.
- Добавлена проверка неправильного выбора клиента, идеи и стиля.
- Служебная кнопка «⬅️ Назад» исключается из списка сохранённых идей.
- Улучшена совместимость со старыми записями в `posts.txt`.
- Улучшена обработка отсутствующих полей в сохранённых постах.
- Результаты поиска отправляются отдельными сообщениями, чтобы снизить риск превышения лимита Telegram.

### Что умеет
- Открывать раздел «Написать пост».
- Показывать меню управления постами.
- Создавать новый пост.
- Загружать сохранённых клиентов из `clients.txt`.
- Преобразовывать строку клиента в структурированную карточку.
- Показывать клиентов кнопками.
- Выбирать сохранённого клиента.
- Создавать пост без клиента.
- Загружать сохранённые идеи из `post_ideas.txt`.
- Показывать идеи кнопками.
- Выбирать сохранённую идею.
- Принимать собственную тему.
- Выбирать стиль поста:
  - экспертный;
  - продающий;
  - дружелюбный;
  - информационный.
- Создавать шаблонный текст поста.
- Сохранять пост в `posts.txt`.
- Сохранять вместе с постом:
  - ID;
  - имя клиента;
  - карточку клиента;
  - тему;
  - стиль;
  - готовый текст.
- Показывать историю последних десяти постов.
- Искать посты по клиенту, теме, стилю или тексту.
- Удалять посты по ID.
- Корректно возвращаться назад между этапами создания поста.
- Возвращаться в главное меню.
- Обрабатывать пустые списки и неправильный пользовательский ввод.

### Выполненная ручная проверка
- Бот успешно запускается.
- Раздел «Написать пост» открывается.
- Сохранённый клиент выбирается кнопкой.
- Сохранённая идея выбирается кнопкой.
- Стиль выбирается кнопкой.
- Пост создаётся и сохраняется.
- Сценарий «Без клиента» работает.
- Сценарий «Своя тема» работает.
- Кнопки «⬅️ Назад» работают.
- История постов работает.
- Поиск постов работает.
- Удаление поста по ID работает.
- Во время выполненной проверки ошибок не обнаружено.

### Ограничения
- Текст поста по-прежнему создаётся по статическому шаблону.
- Данные карточки клиента сохраняются, но пока не влияют на текст поста.
- Нет AI-генерации поста.
- Нет рерайта готового поста.
- Нет генерации нескольких вариантов.
- Нет редактирования сохранённого поста.
- Нет уникальных ID у клиентов и идей.
- При одинаковых именах клиентов возможна неоднозначность.
- Динамические клавиатуры пока не имеют пагинации.
- При большом количестве клиентов или идей клавиатура станет слишком длинной.
- Нет SQLite.
- Хранение остаётся файловым.
- Нет разделения данных между разными пользователями Telegram.

### Почему версия сохранена
- Эта версия завершает интеграцию разделов «Клиенты», «Идеи постов» и «Написать пост».
- Она является итоговой рабочей версией раздела на этапе 2.
- Она сохраняется как основа для будущего архитектурного улучшения и AI-генерации постов.
- Она позволяет позже отдельно восстановить и изучить промежуточные версии v1.1–v1.4.
