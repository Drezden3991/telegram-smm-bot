# v1.1 — AI-генератор семидневного контент-плана

## Что нового относительно v1.0

Статическая генерация заменена на создание структурированного семидневного контент-плана через OpenAI Responses API.

## Что умеет версия

- принимать краткий пользовательский бриф;
- ограничивать бриф 500 символами;
- отправлять запрос через OpenAI Responses API;
- использовать модель `gpt-5.6`;
- использовать `reasoning.effort="low"`;
- получать Structured Outputs через Pydantic;
- создавать ровно семь дней;
- проверять порядок дней от 1 до 7;
- создавать для каждого дня:
  - цель;
  - тему;
  - формат;
  - ключевой тезис;
  - CTA;
- форматировать результат для Telegram;
- разделять длинные сообщения;
- сохранять только полностью валидный результат;
- не сохранять план при ошибке API;
- не заменять старый план при ошибке редактирования;
- обрабатывать ошибки:
  - авторизации;
  - лимитов;
  - соединения;
  - тайм-аута;
  - OpenAI API;
  - неверной структуры ответа;
- использовать один AI-контракт для создания и редактирования;
- выполнять синхронный SDK-вызов через `asyncio.to_thread`;
- сохранять просмотр, поиск, редактирование и удаление.

## Проверка

Выполнены:

- компиляция;
- проверка OpenAI SDK;
- проверка Structured Outputs;
- unit-тесты структуры;
- проверка семи дней;
- проверка порядка дней;
- проверка Telegram-форматирования;
- проверка отсутствия сохранения при ошибке;
- ручной live smoke test через Telegram.

Реальный запрос GPT-5.6 выполнен успешно.

## Ограничения

- клиент не выбирается из сохранённого списка;
- карточка клиента не передаётся в AI;
- сохранённые идеи не используются;
- файловое хранение остаётся неструктурированным;
- нет уникальных ID;
- нет профилей пользователей;
- выбор плана выполняется по номеру.

## Почему версия сохранена

Это первая рабочая AI-функция проекта и отдельный этап развития раздела.

## Что нового относительно v2.0

## Интеграция сохранённых идей

Реализовано:

- загрузка идей из `post_ideas.txt`;
- отдельный этап выбора идей после выбора клиента;
- выбор одной или нескольких идей;
- повторное нажатие снимает выбор;
- выбранные идеи хранятся в FSM;
- кнопка `✅ Готово`;
- кнопка `⏭ Пропустить идеи`;
- запрет продолжения через `✅ Готово` при пустом выборе;
- обработка пустого списка идей;
- обработка неправильного ввода;
- использование одинакового сценария при создании и редактировании;
- сохранение выбранных идей при возврате из брифа;
- добавление выбранных идей в AI-бриф;
- отображение выбранных идей в сохранённом плане;
- поиск контент-плана по тексту выбранной идеи.

## Улучшение выбора идей на телефоне

Вместо длинного текста на каждой кнопке:

- бот отдельно показывает полный пронумерованный список идей;
- кнопки содержат только номера;
- кнопки размещаются по три в строке;
- невыбранная идея обозначается `▫️`;
- выбранная идея обозначается `✅`;
- после каждого изменения показывается актуальный список выбранных идей;
- длинный текст идеи не влияет на распознавание кнопки;
- номер соответствует позиции идеи в `post_ideas.txt`.

Пример клавиатуры:

```text
▫️ 1    ✅ 2    ▫️ 3

✅ Готово
⏭ Пропустить идеи
⬅️ Назад

## Исправление кнопки «⬅️ Назад»

Общие обработчики кнопки «⬅️ Назад» в разделах:

- `clients.py`;
- `post_ideas.py`;
- `write_post.py`;
- `content_plan.py`;

ограничены фильтром:

```python
StateFilter(None)
```

Это предотвращает перехват кнопки общими роутерами во время активного FSM-сценария.

### Переходы при создании

- ввод брифа → выбор идей;
- выбор идей → выбор клиента;
- выбор клиента → меню контент-плана;
- меню контент-плана → главное меню.

### Переходы при редактировании

- новый бриф → выбор идей;
- выбор идей → выбор клиента;
- выбор клиента → выбор плана;
- выбор плана → меню контент-плана.

## Mobile-first выбор контент-плана

Улучшены сценарии:

- `✏️ Редактировать контент-план`;
- `🗑 Удалить контент-план`.

Вместо вывода полного текста всех планов:

- показывается краткий пронумерованный список;
- для каждого плана отображаются клиент и краткий бриф;
- при отсутствии клиента используется текст «Без клиента»;
- краткое название ограничено 80 символами;
- кнопки с номерами расположены по три в строке;
- полный текст показывается только после выбора плана.

Пример:

```text
📋 Выбери контент-план:

1. Анна Смирнова — Продвижение семейной кофейни
2. Без клиента — Контент для онлайн-школы
```
