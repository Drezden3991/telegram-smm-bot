## v1.1 — AI-генератор семидневного контент-плана

### Добавлено

- Интеграция OpenAI Responses API.
- Модель `gpt-5.6` с `reasoning.effort="low"`.
- Structured Outputs на основе Pydantic.
- Семидневная структура с полями: день, цель, тема, формат, ключевой тезис и CTA.
- Краткий SMM-бриф как единый вход пользователя.
- Ограничение брифа до 500 символов.
- Понятная обработка ошибок авторизации, лимита, сети, тайм-аута, статуса API и неверной структуры.
- Unit-тесты API-контракта, форматирования и запрета сохранения при ошибке.

### Изменено

- Создание контент-плана теперь использует GPT-5.6 вместо статического шаблона.
- Редактирование плана регенерирует выбранный план через тот же AI-контракт.
- Синхронный OpenAI SDK запускается через `asyncio.to_thread`, не блокируя aiogram.
- Текст результата адаптирован под сообщение Telegram.

### Безопасность данных

- При ошибке API или неверной структуре план не добавляется и существующий план не заменяется.
- `.env` и значение `OPENAI_API_KEY` во время реализации не читались и не изменялись.
- Реальный API-запрос не выполнялся.

### Архив

Версия v1.0 перед AI-интеграцией сохранена в:

`content_plan_v1_0_before_v1_1_ai_generator.py`
